=head1 NAME

Uji::Driver::GTK4 - Linux/GTK4 backend (not yet implemented)

=head1 DESCRIPTION

L<Uji::Driver::GTK4> is the GTK4 backend for Linux (the C ABI of libgtk-4.so and libglib-2.0.so). It subclasses
L<Uji::Driver|Uji::Driver> and currently provides B<no implementations> of the driver surface: the stub methods it
inherits from Uji::Driver are placeholders.

The backend is on the roadmap (see the framework's C<TODO.md>). Until it lands, L<Uji::Driver/detect> dies on any
non-Win32 platform, so the toolkit is Windows-only in practice.

=head1 SEE ALSO

=over

=item * L<Uji::Driver> - the base class and factory (the surface this backend must implement)

=item * L<Uji::Driver::Win32> - the shipping Windows backend, the reference implementation

=back
