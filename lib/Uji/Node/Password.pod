=head1 NAME

Uji::Node::Password - a masked single-line text editor

=head1 SYNOPSIS

    use Uji;

    Uji::password(
        value         => $model->{secret},
        password_char => '*',
        focused       => 1,
        on_input      => sub ($text) { { type => 'SET_SECRET', value => $text } }
    );

=head1 DESCRIPTION

L<Uji::Node::Password> is a masked variant of L<Uji::Node::TextInput|Uji::Node::TextInput>. The native display is
replaced by bullets (E<sol>E<gt>C<ES_PASSWORD>), but the I<message payload is the plain text she typed>, so the model
stores and receives the real value. Everything C<TextInput> supports - C<value>, C<on_input>, C<readonly>,
C<maxlength>, C<focused>, and the common parameters - applies unchanged.

=head1 Constructor

=head2 C<new ( %params )>

You normally use the L<Uji|Uji/password> helper. Parameters are identical to
L<Uji::Node::TextInput|Uji::Node::TextInput/new>.

=head3 Parameters

=head4 C<password_char>

The character displayed in place of each typed character. Win32 accepts any Unicode code point but only uses the first
one. C<undef> (default) lets Windows choose its standard bullet. Recomposed live (requires C<recreate_node>; see
L<Uji::Reconciler/Recreation>).

=head3 Inherited Parameters

Inherits from L<Uji::Node::TextInput|Uji::Node::TextInput/Parameters>, which in turn inherits the common parameters
from L<Uji::Node|Uji::Node/Parameters>.

=head1 Methods

=head2 C<value>

Returns the plain-text value (the masked text is only a display property).

=head2 C<on_input>

Returns the callback (or C<undef>).

=head2 C<readonly>, C<maxlength>, C<focused>

Return the current parameter values.

=head2 C<password_char>

Returns the configured mask character (or C<undef>).

=head2 C<type>

Returns the string C<'password'>.

=head1 How it Works

On Win32 this is an C<EDIT> control created with C<ES_PASSWORD> (C<WS_CHILD | WS_VISIBLE | WS_BORDER | ES_PASSWORD |
ES_AUTOHSCROLL>). As with C<TextInput>, edits post C<EN_CHANGE> and C<SetWindowTextW> updates are suppression-wrapped
so they never echo back into the model.
