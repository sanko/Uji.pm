=head1 NAME

Uji::Node::Separator - a thin ruled divider between siblings

=head1 SYNOPSIS

    Uji::column(
        children => [
            Uji::text('Above'),
            Uji::separator(),                # horizontal rule across the column
            Uji::text('Below'),
        ],
    );

    Uji::row(
        children => [
            Uji::button( label => 'Save' ),
            Uji::separator( orientation => 'vertical' ),
            Uji::button( label => 'Cancel' ),
        ],
    );

=head1 DESCRIPTION

A Separator draws a thin etched line dividing adjacent siblings: horizontal across a column
(crossing the full column width), vertical down a row (crossing the full row height). The rule
thickness is built into the layout algorithm (3px on the perpendicular axis), and the 
cross-axis span is automatic, so a separator needs no C<w>/C<h>. On Win32 it is a native
C<STATIC> control with C<SS_ETCHEDHORZ> (0x10) or C<SS_ETCHEDVERT> (0x11).

=head2 Parameters

=over

=item C<orientation>

C<'horizontal'> (default, for a rule in a column) or C<'vertical'> (for a rule in a row). A
mount-only parameter: changing it destroys and recreates the native control.

=back
