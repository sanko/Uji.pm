=head1 NAME

Uji::Node::Slider - a horizontal or vertical range slider

=head1 SYNOPSIS

    use Uji;

    Uji::slider(
        value       => $model->{level},
        min         => 0,
        max         => 100,
        step        => $model->{locked} ? 25 : 1,
        orientation => 'horizontal',
        on_change   => sub ($v) { { type => 'SET_LEVEL', value => $v } }
    );

=head1 DESCRIPTION

L<Uji::Node::Slider> is a range slider whose position is bound to the model. Dragging (or pressing the arrow keys)
fires L</on_change> with the new numeric position; the model writes C<value> back and the reconciler repositions the
thumb only when necessary. The default orientation is horizontal; pass C<orientation => 'vertical'> for a vertical
track.

=head1 Constructor

=head2 C<new ( %params )>

You normally use the L<Uji|Uji/slider> helper.

=head3 Parameters

=head4 C<value>

The current position. Default C<0>. Recomposed live.

=head4 C<min> / C<max>

The range endpoints. Defaults C<0> / C<100>. Recomposed live (the native range is replaced).

=head4 C<step>

The increment used by the arrow keys (and page/line sizing). Default C<1>. Recomposed live.

=head4 C<orientation>

C<'horizontal'> (default) or C<'vertical'>. Recomposed live (requires C<recreate_node>; see
L<Uji::Reconciler/Recreation>).

=head4 C<on_change>

A callback receiving the numeric position whenever the user moves the thumb:

    on_change => sub ($value) { { type => 'SET_LEVEL', value => $value } }

Return a message hashref (or C<undef>). The position is read from the native control at event time (C<TBM_GETPOS>).

=head3 Inherited Parameters

L<Uji::Node::Slider> inherits the common parameters from L<Uji::Node|Uji::Node/Parameters>: C<flex>, C<enabled>,
C<visible>, C<tooltip>, C<x>/C<y>/C<w>/C<h>, C<color>, C<background>, C<font>, C<font_size>, and C<id>.

=head1 Methods

=head2 C<value>

Returns the current position.

=head2 C<min>, C<max>, C<step>

Return the current range/step parameters.

=head2 C<orientation>

Returns C<'horizontal'> or C<'vertical'>.

=head2 C<on_change>

Returns the callback (or C<undef>).

=head2 C<type>

Returns the string C<'slider'>.

=head1 How it Works

On Win32 this is a C<msctls_trackbar32> control (C<WS_CHILD | WS_VISIBLE | TBS_AUTOTICKS | TBS_HORZ>, plus C<TBS_VERT>
for vertical sliders), registered with C<InitCommonControlsEx> at driver construction. Mount and live updates use the
trackbar messages C<TBM_SETRANGE>/C<TBM_SETPOS>/C<TBM_SETLINESIZE>/C<TBM_SETPAGESIZE>. Horizontal drags arrive as
C<WM_HSCROLL>; vertical drags arrive as C<WM_VSCROLL> with the trackbar's own handle as C<lParam>. Either way the
driver reads the position back and fires C<on_change>.
